# design/ is the design source of truth (reference only)

This folder holds the **static design mockups** (plain HTML/CSS/JS) and the
product spec (`SPEC-*.md`). It is the reference the real app is built from — it
is **not** the deployable site.

The actual web app is the Next.js project in [`../frontend/`](../frontend).
For running and deploying it (Vercel), see [`../frontend/README.md`](../frontend/README.md).

To browse these static mockups locally, open `index.html` in a browser or serve
the folder with any static file server.
